# Dragons Island

Jeu de capture et de combat de dragons en 3D (bêta). Trois îles (Feu, Glace, Eau), un couvoir pour faire éclore des œufs, et des combats en 9 tours où chacun choisit en secret son dragon et sa posture.

**Jouer :** ouvre la page GitHub Pages de ce dépôt sur ton téléphone ou ton ordinateur.

- **Défi en ligne :** dans Combat, « Défi en ligne (code ami) ». L'un crée une partie et envoie le code ou le lien, l'autre le tape. Chacun joue sur son téléphone.
- **Sauvegarde :** la partie est gardée dans le navigateur de chaque appareil.
- **Boutique :** pendant la bêta, les achats sont simulés et gratuits.
- **Livre des dragons :** le dossier `livre/`.

Page statique (HTML et modules JavaScript, Three.js r128). La connexion entre amis passe par PeerJS (WebRTC).
